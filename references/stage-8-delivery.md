# 阶段 8 · 交付与复盘

> 来源：v2 阶段 8 + 附录 C §7–9。v3 变化：终检增加品牌 / UGC / 多画幅条目；合规与平台规格拆到 `compliance-and-delivery-specs.md`；复盘加入「A/B 测试结果回填」。

## 步骤

1. **终检清单**（逐项让用户勾选）：
   - [ ] 角色 / 产品跨镜头一致
   - [ ] 没有明显变形、闪烁、多余肢体、乱码文字
   - [ ] 帧率统一，没有卡顿、重复帧、黑帧
   - [ ] 全片连看没有风格跳变
   - [ ] 对白清晰，响度和真峰值达标
   - [ ] 字幕、品牌、文字准确（品牌项目：对照 `brand-consistency-checklist.md` 终核）
   - [ ] 画幅、安全区和平台规格正确（每个交付画幅都单独看过）
   - [ ] 音乐、肖像、声音、品牌授权齐全
   - [ ] 按平台和法规要求标注 AI 生成内容（见 `compliance-and-delivery-specs.md`）
   - [ ] 广告用语合规已由客户 / 法务确认【待核】
   - [ ] 客户审批记录已留存
2. **导出**：存档母版 ProRes 422 HQ 或等价高质量中间格式；平台版 H.264 / HEVC，按平台推荐参数【待核】；需要分轨时导出多轨文件。
3. **多版本**：按平台需要输出 16:9 / 9:16 / 1:1 / 4:5；**重新构图，不是简单裁切**，逐版检查主体、字幕、Logo 位置。
4. **发布素材**：封面 / 首帧（承接钩子）、标题与简介文案、AI 生成标注、变体命名（UGC：钩子编号 + 受众 + 日期）。
5. **合规**：见 `compliance-and-delivery-specs.md`。真人肖像和声音克隆需要书面授权；商用条款因工具与套餐而异【待核】。
6. **归档**：项目资料库、原始素材、生成记录、资产库 v1.x、母版、分轨、授权清单、客户批示放在同一项目目录。
7. **复盘**：

   | 问题 | 记录 |
   | --- | --- |
   | 哪些路线最稳定？ | |
   | 哪类镜头返工最多？根因是创意、一致性、动作还是工具？ | |
   | 哪些工具真正省时？ | |
   | 实际与计划：镜头数、时长、费用、周期 | |
   | 回退发生在哪个阶段、为什么？ | |
   | （v3，UGC / 投放）哪个「购买理由」和哪个钩子表现最好？回填到下一批脚本 | |
   | 下次应在哪个阶段提前解决什么？ | |

8. **指标**：每秒成片总成本 =（生成费用 + 修复工时 × 费率 + 剪辑 / 声音工时 × 费率）÷ 成片秒数【计算公式】；A 类镜头首轮通过率；每个入选镜头的平均候选数；回退次数和阶段；交付缺陷数；发布后对照阶段 1 的成功标准。指标只用于改进流程，不用作个人绩效考核。

**交付物**：交付清单 + 复盘表。
