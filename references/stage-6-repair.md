# 阶段 6 · 修复与增强

> 来源：v2 阶段 6（修复决策树保留）。v3 变化：工具中立；新增「只重做声音，不重做画面」与「放大放在锁剪后」的社区印证。

**目标**：在可控成本内把通过版修到技术合格。

## 步骤

1. **QC 观看**：每个通过镜头先正常速度看一遍，再在问题区域逐帧检查，记录问题和时间码。
2. **修复决策树**（按顺序判断）：
   1. 剪掉、缩短或换剪切点能解决吗？→ 剪辑解决
   2. 声音、字幕或相邻镜头能转移注意力吗？→ 声音 / 剪辑解决
   3. 是局部问题，且修复成本低于重新生成吗？→ 局部修复
   4. 都不行 → 重新生成；连续 3 轮失败 → 重新设计镜头
3. **按问题处理**：

   | 常见问题 | 首选处理 | 工具类别 |
   | --- | --- | --- |
   | 闪烁 | 去闪烁；降低运动强度后重新生成 | 剪辑 / 调色软件的去闪烁、专用增强工具 |
   | 面部漂移 | 缩短镜头、改景别，或用身份一致性工具 | 剪辑、视频到视频工具 |
   | 手部 / 道具变形 | 在变形前剪切、遮挡、局部修复 | 合成软件 |
   | 文字 / Logo 错误 | 跟踪后贴回真实素材（品牌项目：用客户提供的矢量 Logo） | 合成软件、跟踪器 |
   | 多余物体 | 遮罩 + 内容填充 | 合成软件 |
   | 运动卡顿 / 帧率混杂 | 见阶段 7 帧率处理 | NLE 的帧率转换、增强工具 |
   | 分辨率不足 | 锁剪后再放大 | 专用放大工具 |
   | 声音不对、背景音乐多余（v3） | **只重做声音，保留画面**：去掉模型自带的背景音，用分轨声音重建 | 声音工具 / DAW；社区已有专门工具（见 `tools.md`） |

4. **放大与补帧放到锁剪之后**，只处理最终入选片段；放大到交付分辨率即可，避免过度锐化和人脸「塑料感」；颗粒在放大之后加。【通用】
   - X 上有创作者展示了 480p 源片经放大工具放到 4K 的对比，并说明不同放大模型的取舍（锐度 vs 柔和 vs 渲染时间，见 `research-notes-x.md` §5）；这是个人展示，**不代表对所有片源都成立，上线前对 A 类镜头逐个目检**。
5. **往返规范**：带首尾余量导出单个镜头到合成软件；需要 Alpha 时用 ProRes 4444 或等价格式；原素材、修复工程、修复版使用同一镜头编号；回到剪辑软件后用替换 / 版本切换换入。
6. **复检**：修复版再做一次 QC。

**Gate**：通过技术 QC——无闪烁、变形、错帧，修复边缘不可见；品牌项目的 Logo / 产品逐帧核对通过。
