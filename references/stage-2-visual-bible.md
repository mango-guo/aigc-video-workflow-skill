## 2B 参考分析

逐张查看用户上传的图片（必须先看图再分析），每张输出一张分析卡：

```text
参考 #01：（文件名）
用户想取：
媒介 / 风格流派：写实摄影 / 胶片 / 插画 / 3D / 动画 / ……
色彩：主色 ___ 辅色 ___ 点缀色 ___（估算 HEX）· 饱和度 · 冷暖

构图：主体位置、留白、前景层次
镜头感：景别、焦段感、景深
纹理：颗粒、锐度、光晕、暗角、色差
情绪关键词：3 个
可提取的提示词（英文）：
不应继承的部分：（如特定人物的脸、Logo、水印、文字）
```

全部分析后，输出综合判断：**共同特征**、**冲突点**（例如一张冷调、一张暖调）、**建议的主参考**。存在冲突时让用户选主参考，其余降为局部参考（例如“只取 #03 的光线”）。

**提取色值**：用户上传图片后，可在有 Python + Pillow 的电脑上运行以下脚本提取主色（没有就改用取色器手动取）：

```python
from PIL import Image
def palette(path, n=6):
    img = Image.open(path).convert("RGB")
    img.thumbnail((300, 300))
    q = img.quantize(colors=n, method=Image.Quantize.MEDIANCUT)
    pal = q.getpalette()[: n * 3]
    counts = sorted(q.getcolors(), reverse=True)
    total = sum(c for c, _ in counts)
    return [("#%02X%02X%02X" % tuple(pal[i*3:i*3+3]), round(c / total * 100, 1)) for c, i in counts]
print(palette("ref_01.jpg"))  # [('#2E3A4B', 31.2), ...] 色值 + 占比 %
```

## 2C 风格方向：给出 2–3 个方向供选择

每个方向用同一格式呈现：

| 方向 | 一句话 | 风格块草案（英文） | 色调 | 镜头感 | 适合 | AIGC 难度 |
| --- | --- | --- | --- | --- | --- | --- |
| A 写实胶片 | 温暖、真实的生活片段 | cinematic realism, 35mm film look, soft natural window light, muted teal and warm amber, fine film grain | 青 + 琥珀 | 35–50mm、浅景深 | 品牌情感片、叙事 | 中高 |
| B 风格化 3D | 柔和、可爱、明亮 | stylized 3D animation, soft global illumination, rounded shapes, pastel palette, clean render | 粉彩 | 中景为主、深焦 | 儿童、科普、IP | 中 |
| C 超现实拼贴 | 梦境、荒诞、记忆感 | surreal collage, analog photography textures, dreamlike lighting, faded colors | 褪色暖调 | 固定机位、对称 | MV、概念片 | 低（漂移可当风格） |

**常用风格谱系**（供选择或混合）：写实电影感 · 纪实手持 · 高级商业广告 · 复古胶片 · 日系清新 · 赛博霓虹 · 黑色电影 · 赛璐璐动漫 · 风格化 3D 动画 · 黏土定格 · 水墨国风 · 绘本插画 · 超现实 · 极简几何。

**规则**：

- 不在提示词中点名在世艺术家、受保护的工作室或 IP；改用可描述的视觉特征。
- 与阶段 1 的风格定位一致；若冲突，回到阶段 1 修改风格定位。

**风格三连测**：用户选定方向后，用同一风格块生成三类测试图：① 人物中景 ② 场景远景 ③ 物体特写，每类 2–4 张【建议值】。三类图都像“同一部片”才算风格块成立；某一类偏离时，只修改风格块中导致偏离的词。

## 2D 角色设计与定稿

**1. 角色档案**

```text
ID：CHR_A
名称 / 角色功能：
年龄感 / 体型 / 身高比例：
锚点特征（3–5 个，跨镜头必须保持）：
  - 发型与发色：
  - 标志性服装颜色：
  - 标志性配饰：
  - 轮廓特征（体型、帽子、发型剪影）：
服装 v1：款式 + 颜色 + 材质
表演基调：动作幅度、表情习惯、节奏
禁止变化项：
```

锚点特征优先选**大面积、高对比、可在远景识别**的元素（发型、服装主色、配饰）；不要只依赖细微面部特征，这些最容易在生成中漂移【推断】。

**2. 选角路线**

| 路线 | 一致性难度 | 合规 | 推荐方法 |
| --- | --- | --- | --- |
| 虚构写实人物 | 高 | 避免酷似真实人物 | 多参考图 + 设定表，必要时训练 LoRA |
| 真人授权（本人或演员） | 中 | 必须书面授权 | 实拍照片做参考，或表演驱动、实拍混合 |
| 风格化角色 | 中低 | 低 | 设定表 + 锚点配色 |
| 非人类角色（吉祥物、动物、生物） | 低 | 注意与已有 IP 区分 | 强轮廓 + 固定配色 |

**（v3 增补）面部与角色锁定的三条低成本做法**（均为 X 创作者的做法，见 `research-notes-x.md` §3）：① 四视图（正 / 侧 / 背 / 3/4）锁脸；② 把角色设定表的姿态行直接当作镜头清单；③ 做 AI 达人 / UGC 角色时，用结构化描述（脸型、皮肤质感、眼睛、发型、表情、服装、光线、机位、环境）约束图像模型，目标是「新角色」，不是复刻某个真人。

**3. 候选生成**：中性灰背景、柔和正面光、正面半身，出 6–12 张候选【建议值】，用户选 1–2 张作为基准。

**4. 角色设定表（character sheet）**

- 全身转面：正面 / 3/4 侧 / 侧面 / 背面
- 头像特写：正面 / 3/4 侧
- 表情 6 个：中性、开心、悲伤、愤怒、惊讶、思考
- 服装与配饰细节图 + 色卡

示例提示词：`character turnaround sheet of CHR_A, front view, three-quarter view, side view, back view, full body, consistent outfit and hairstyle, neutral grey background, even soft lighting` + 风格块。用支持多参考图的编辑模型，以基准图为参考生成。

**5. 一致性固化（由轻到重）**

| 级别 | 方法 | 适用 |
| --- | --- | --- |
| L1 | 每次生成都附 2–4 张定稿参考图 | 大多数项目 |
| L2 | 使用图像 / 视频工具的角色、主体或参考功能【待核】 | 角色出场多 |
| L3 | 训练角色 LoRA：15–30 张多角度、多表情、多光线图【建议值】 | 长片、系列内容、IP |
| L4 | 表演驱动或实拍混合 | 需要精确表演和口型 |

**6. 一致性测试**：同一角色 × 5 个条件（远景、中景、特写、逆光、夜景）各出 1–2 张。锚点特征全部保持才算通过；失败时先强化锚点描述，再升级一致性级别。

**7. 多角色**：同框 ≤ 2 个主要角色；每个角色用不同主色和轮廓区分；同框时用多参考图，并在提示词中按画面位置描述（`CHR_A on the left, CHR_B on the right`）。

## 2E 产品资产

> v3：品牌项目的产品与 Logo 准确性，统一用 `brand-consistency-checklist.md` 建档和验收；本节只保留生产路线。

- **实物优先**：产品外观以实拍为准，生成只负责环境、光线和氛围。
- **（v3 增补）产品参考板（product reference sheet）**：把实拍产品图作为「唯一事实来源」，生成一张多视角参考板（正 / 侧 / 背 / 开合或截面 / 包装正面），之后每个镜头的首帧都附这张板。X 上有人的提示词写明「参考图是产品设计、包装、Logo、字体、比例、颜色的唯一依据（REFERENCE LOCK）」（`research-notes-x.md` §3）。注意：那个例子里品牌是虚构的；真实品牌仍以实拍与矢量 Logo 为准，Logo 在后期贴回。
- **推荐路线**：实拍产品图 → 抠图 → 用编辑模型放入场景做首帧 → 图生视频时只让环境或镜头运动，产品本身尽量少动。
- **Logo 与文字**：一律在后期用真实矢量文件贴回、跟踪，不依赖模型生成。
- **主体 ID 块**中写清材质：磨砂铝、透明玻璃、哑光塑料、亮面陶瓷等。
- **准确性检查表**：形状比例 · 颜色色值 · Logo 位置与比例 · 文字 · 包装细节 · 按键与接口数量。

## 2F 场景设计

```text
ID：LOC_01
地点 / 时代 / 地域：
时间 / 天气：
空间布局（文字平面图）：入口在画左，窗户在画右，长椅在中央……
主光源方向与色温：窗光自画右进入，约 5600K；顶灯暖黄补光
关键道具：
场景色彩：
声音氛围：（与阶段 1 的环境声对应）
```

为每个场景生成：**主图**（establishing wide）1 张 + **不同机位** 2–3 张（含反打）+ **空镜底片**（无人物，用于合成或过渡）。同一场景的所有镜头都以主图为参考，保持布局和光源方向一致。

## 2G 调色板与色彩脚本

- **调色板**：5–7 色，标 HEX；按 60-30-10 分配（主色 60%、辅色 30%、点缀色 10%）【通用】。
- **角色专属色**：每个主要角色一个识别色，不与背景主色冲突。
- **色彩脚本**：按阶段 1 的段落画出色温和饱和度变化，例如：

| 段落 | 色温 | 饱和度 | 对比 | 情绪 |
| --- | --- | --- | --- | --- |
| 钩子 | 冷蓝 | 低 | 中 | 停滞、悬念 |
| 转折 | 冷转暖 | 中 | 中高 | 苏醒 |
| 高潮 | 暖橙 | 高 | 高 | 释放 |
| 结尾 | 自然 | 中 | 中 | 平静 |

## 2H 全片镜头语言规则

```text
主要景别分布：如 远景 20% / 中景 50% / 特写 30%
焦段范围：如 只用 35mm 与 85mm 两种焦段感
景深：浅景深为主 / 深焦为主
运动规则：允许的运镜（如 固定、缓推、缓拉）；运动幅度上限（slow / subtle）
禁用：如 快速甩镜、斜角、FPV
构图偏好：如 对称 + 大量负空间
主体朝向规则：如 主角始终朝画右前进，象征“向前”
画幅与安全区：9:16 时主体与字幕避开顶部 15%、底部 20%【建议值，以平台为准】
```

## 2I 纹理与光学质感

确定以下参数并同时写进风格块和阶段 7 的调色方案，保证生成与后期一致：

- 颗粒：无 / 细 / 中 / 粗
- 锐度：柔和 / 自然 / 锐利
- 光晕（bloom / halation）：无 / 轻微 / 明显
- 暗角、色差、镜头畸变
- 媒介感：数码电影 / 35mm 胶片 / 16mm 胶片 / 录像带 / 手绘
