# 阶段 0 · 立项简报

> 来源：v2 阶段 0 + 第四节「识别输入」。v3 增补：简报加入「项目类型」「客户审批链」「素材与授权」三栏，品牌 / UGC 项目必填。

**目标**：说清为什么做、给谁看、观众看完记住什么；确定交付规格、禁区和审批链。

## 步骤

1. 按下方「识别输入」解析用户给的东西，用 1–2 句复述你理解的创意。
2. 起草 2–3 个一句话概念，公式：「给【谁】看一个【类型 / 形式】，用【核心画面或手法】，让他们【感受 / 记住 / 行动】」。
3. 判定**项目类型**（UGC 种草 / 产品广告 / 品牌宣传片 / 叙事短片 / MV），它决定后续哪些阶段可合并、哪些不能省（见 SKILL.md「项目类型」）。
4. 按平台补齐规格。默认值【假设】：社媒 9:16、15–60 秒、30fps、1080×1920；广告和短片 16:9、24fps、1920×1080 或 3840×2160。平台细则见 `compliance-and-delivery-specs.md`。
5. **风险扫描**：真人肖像、名人、品牌 Logo、受版权保护的角色或音乐、声音克隆、敏感品类（医疗 / 保健 / 金融 / 儿童）；每项标高 / 中 / 低和处理方式。
6. **资源盘点**：预算、周期、人手、已有工具账号、是否能实拍产品、是否能自己配音、是否有真人出镜授权。
7. **审批链**（v3）：谁在哪个节点签字（脚本 / 分镜 / 样片 / 终片）；客户只给反馈还是有否决权。

## 识别输入，确定入口

| 用户输入 | 你的解析动作 | 入口阶段 |
| --- | --- | --- |
| 一句话想法、模糊灵感 | 提炼 2–3 个一句话概念，各附形式和风格建议 | 0 |
| 文案、旁白、完整脚本 | 判断结构（钩子 / 展开 / 转折 / 收尾）是否成立，按字数估算时长 | 补齐阶段 0 缺项后进 1 |
| 单张图片 | 先看图再描述主体、风格、色彩、构图、光线、镜头感；判断用途：情绪参考、角色定稿、关键帧候选或产品实物 | 0 或 2 |
| 多张图片 / 情绪板 | 提取共同风格；有冲突时指出冲突点，请用户选主参考 | 0 或 2 |
| 参考视频或链接 | 能打开就拆解节奏、平均镜头时长、景别分布、色调、声音结构；打不开就请用户截图或描述 | 0 |
| 品牌 brief、产品资料、VI 手册 | 提取目标、受众、必须出现的信息、禁区、审批人；转成 `brand-consistency-checklist.md` | 0 |
| 已生成的素材、半成品 | 先按四级筛选诊断，定位问题属于哪个阶段 | 5–7 |
| 纯技术问题 | 直接回答，再问是否纳入一个项目 | — |

## 交付物：一页简报

```text
项目名：
项目类型：UGC种草口播 / 产品广告片 / 品牌宣传片 / 叙事短片 / MV
一句话概念：
用途 / 平台 / 投放方式（自然流 / 付费投放 / 线下大屏）：
目标观众：
观众看完应记住：
时长 / 画幅（含需要的多画幅版本）/ 帧率 / 分辨率：
风格参考：
必须出现（产品 / Logo / 卖点 / 法定文字）：
禁止 / 风险（禁用词、禁用画面、竞品、敏感品类）：
素材与授权（实拍产品素材？真人出镜授权？音乐 / 声音来源？）：
预算 / 周期 / 人员 / 已有工具：
审批人与审批节点：
成功标准（可衡量：留存 / 点击 / 转化 / 客户签收）：
```

**Gate**：能用一句话回答「为什么做、观众记住什么」；规格和画幅版本已定；授权风险已标出；审批链已写明。

**常见坑**：概念只是「画面很酷」；平台没定，后期返工画幅；忘记确认用户已有哪些工具；品牌项目到阶段 5 才发现客户有 Logo 版本或禁用词要求。
