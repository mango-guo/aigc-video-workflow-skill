# 阶段 7 · 剪辑、声音、调色

> 来源：v2 阶段 7 + 附录 C §6（Final Cut Pro 专有内容）。v3 变化：主文本改为**工具中立**，FCP 的做法收进每节末尾的「可选软件备注」；新增 UGC 剪辑和「声音分轨」的社区印证。

按顺序引导，每完成一项让用户确认。适用软件：剪映 / CapCut、Premiere、Final Cut Pro、DaVinci Resolve 均可。

## 1. 入库前检查
- 检查**帧率（含可变帧率）、分辨率、色彩标签、编码**（MediaInfo / ffprobe 或软件自带检查器）。【通用】
- 可变帧率或长 GOP 的 H.264 / H.265 素材，先转中间编码（如 ProRes 422）或使用软件的优化媒体 / 代理，再剪辑。
- 色彩标签缺失的素材可能出现 gamma / 饱和度偏移；SDR 项目统一按 Rec.709 处理。【通用】
- 命名：`项目_场次_镜头_路线_版本`（如 `ABC_SC010_SH020_I2V_v003.mov`）。
- 可选软件备注（FCP）：混合帧率片段在检查器里逐个设 Rate Conform（Floor / Nearest Neighbor / Frame Blending / Optical Flow），Optical Flow 在快速运动与遮挡处易出伪影，需逐帧看【已知】。

## 2. 项目设置
一个时间线只用一个帧率，按交付规格（见 `compliance-and-delivery-specs.md`）设画幅。更稳的做法：生成时就按目标帧率输出，或入库前统一转换。

## 3. 目录与版本
`01_REF · 02_KEYFRAMES · 03_GEN_SELECTS · 04_GEN_ALL · 05_REPAIR · 06_AUDIO · 07_TIMELINES · 08_EXPORTS`；每次大改复制项目（如 `ABC_Edit_v05_2026-10-28`）；媒体放外部存储，母版永远保留。可选（FCP）：用关键词集合 + 收藏 / 拒绝对应四级筛选。

## 4. 剪辑顺序：粗剪 → 精剪 → 锁剪
- 粗剪：按 animatic 换入通过版，先看叙事和节奏。
- 精剪：**在生成伪影出现之前剪掉**；多用动作剪辑和遮挡剪辑；J-cut / L-cut 让声音先行；同一镜头的候选并排比较（FCP 的 Auditions，或其他软件的多机位 / 轨道叠放）。
- **（v3）AI 初剪可以交给助手，但第一版永远不是终版**：X 上有创作者让 AI 助手先在剪辑软件里搭粗剪，再人工精修，并强调「第一次 AI 输出不当成最终版」（`research-notes-x.md` §7）。保留人对节奏的最终决定权。
- 锁剪：时长和顺序不再变动，然后才放大、补帧、精修（回阶段 6）。
- **UGC 剪辑（v3）**：节奏快、字幕大、少花哨转场；保留自然的小瑕疵；细则见 `ugc-playbook.md`。

## 5. 声音顺序与分轨
对白 / 旁白剪辑与降噪 → 音乐剪辑（重拍落在剪切点）→ 环境声铺底（每个场景至少一层）→ 动作音效对点 → 强调和转场音效 → 混音 → 响度。
- **分轨**：对白 / 旁白、音乐、环境、音效、强调各自独立轨，**修一个不用重做其他**（X 上有创作者明确这样做）。
- **配音来源（社区有分歧，不预设）**：一派认为模型自带声音「听起来像 AI」，建议用独立配音工具生成人声，再作为音频参考送入视频模型做口型；另一派认为原生口型 + 声音在低成本口播上够用。见 `ugc-playbook.md` 与 `research-notes-x.md` §4。成片音质以听感为准，不预设。
- 原生音频适合做临时版；最终版优先使用分轨、可控的声音。【通用】
- 响度：流媒体 / 社媒参考约 -14 LUFS integrated，广播 EBU R128 为 -23 LUFS，真峰值 ≤ -1 dBTP；以平台规范为准。【已知 / 通用，平台值待核】
- 可选（FCP）：Roles 分 Dialogue / Music / Effects + 子角色 VO、AMB、SFX；分轨导出在「共享 → 母版文件 → 角色」；复杂混音经 FCPXML 送 Logic Pro【已知】。

## 6. 调色与统一
顺序：色彩标签检查 → 每镜头基础校正 → 以 A 类英雄镜头为基准做匹配 → 全片风格（LUT / 预设）→ 纹理（颗粒、轻微光晕、暗角，按阶段 2 参数）→ 用波形与矢量示波器检查。目标是让所有镜头属于同一个世界，不是每个镜头都一样。颗粒要在放大之后加。品牌项目：品牌色必须在示波器 + 色值取样上核对，见 `brand-consistency-checklist.md`。

## 7. 字幕
字号在手机上清晰可读；描边或底条保证对比；9:16 版本避开平台 UI 遮挡区；中文每行约 ≤ 16 字【建议值】；与旁白逐字核对。

## 8. 算力分工
重型开源视频模型多优先支持 NVIDIA 显卡，Mac 上的速度与兼容性不确定。实务做法：视频生成用托管 API 或云 GPU，本机负责剪辑与后期。上传前确认素材保密要求和授权。【通用】

**Gate**：全片连看无风格跳变；对白清晰；响度达标；字幕准确；品牌项目的色彩与 Logo 终核通过。
