# 合规与交付规格

> **重要**：本文件不是法律意见。法规与平台规则会变；X 上我检索到的相关内容多为新闻 / 创作者转述，没有法条原文和平台规格页（`research-notes-x.md` §9）。凡数值与法条，统一标 **【待核】**：以现行官方文本、平台后台提示、客户法务意见为准，**交付前请你本人核对**。没有核对过的数字，不要直接写进给客户的交付规格。

## 1. AI 生成内容标识

| 范围 | 已知信息 | 状态 |
| --- | --- | --- |
| 中国 | 《人工智能生成合成内容标识办法》自 2025-09-01 起施行，要求显式和隐式标识（来自 v2） | 【已知·v2】，具体条款与适用主体【待核】 |
| 欧盟 | AI Act 对深度伪造和部分 AI 生成内容有透明度义务；运营类账号称「不论公司所在地」（`research-notes-x.md` §8 socialpilot_co，粗略转述） | 【待核】 |
| YouTube | 官方客服答复：对使用其生成式工具、含 C2PA 元数据、或系统检测到的 AI 内容，可自动加标签（https://x.com/TeamYouTube/status/2102085190436725041 ）；创作者转述：对未披露的显著写实 AI 内容可能加标签（https://x.com/successfaceless/status/2112944501866291384 ） | 【待核·以后台为准】 |
| TikTok / Meta 等 | 汇总帖称各大平台都要求披露，TikTok 会在文件含内容凭证时自动加标签（https://x.com/buzz_voice/status/2106448330641244289 ，个人账号转述）；有创作者抱怨被自动加标签且无法申诉（https://x.com/kidovna/status/2103001855290941848 ） | 【待核】 |

做法【我的经验判断】：

- 发布时使用**平台提供的 AI 披露开关**；同时在画面角落或描述里加文字标识（按适用法规与客户要求）。
- 保留生成记录（工具、日期、素材来源、授权），遇到平台申诉时有据可查。
- 自动标签可能被平台打上，投放前与客户讲明这一风险。
- 「AI 生成」标注对部分观众几乎无效，不要把标注当作规避误导风险的手段（https://x.com/JustOnDiFi/status/2113481664907329557 ，个人观点，转述新闻）。

## 2. 广告用语与代言

> 以下是我对中国大陆广告场景的**常识级提示**，没有在 X 上找到法条原文。具体条文号与表述一律【待核·以现行文本为准】。

- **绝对化用语**：广告法对「最」「第一」「国家级」等绝对化用语有限制（v2 外我的经验；条款号【待核】）。脚本钩子最容易踩。
- **功效 / 医疗 / 保健 / 金融 / 儿童**类：禁止暗示治疗、保证收益、夸大功效；必须客户法务确认（硬规则）。
- **代言与亲身体验**：真人代言要求代言人真的使用过产品（条款【待核】）。**AI 角色没有「用过」这回事**——不要让 AI 数字人以第一人称宣称「我用了一天很舒服」。央视曝光过的案例：AI 数字人以第一人称称「我的美瞳戴了一天，都很舒服」被质疑（https://x.com/balon_f3/status/2114698153173905513 ，转述）。UGC 脚本里的「亲测」「我用了 N 天」一律需要真实依据，否则改写成「演示」「展示」。
- **医生 / 专家 / 患者形象**：禁止用 AI 角色冒充真实职业身份背书。
- **价格、折扣、赠品、限时**：以客户提供为准，逐字核对。
- **对比广告**：贬低竞品或比较需要依据。

## 3. 肖像、声音、版权

- **真人肖像、声音克隆**：必须**书面授权**（范围、期限、用途、是否允许 AI 生成）。创作者提示：「形象用自己的或已授权的，发布时标注 AI 生成，别拿别人的脸」（https://x.com/jackcorleone19/status/2111082764107723086 ）。
- 最高法发布涉人工智能纠纷的司法意见，据转述涉及 AI 换脸、声音克隆、仿冒名人带货等（https://x.com/xiarenreal/status/2097912123888435669 、https://x.com/YoooJJ8cm/status/2097097413005816160 ）。**我没有读到原文，不引用其具体条款**【待核】。
- **名人 / 在世人物 / 已故人物**：默认不做。
- **音乐**：商用授权（平台曲库 ≠ 品牌投放授权）；AI 生成音乐也需确认工具的商用条款【待核】。
- **品牌与第三方 Logo、角色、受版权保护的画面**：不入镜或取得授权。
- **生成工具的商用条款与数据隐私**：因工具与套餐而异；未发布产品和肖像的上传前先看条款【待核】。
- **授权清单**：每个人物 / 声音 / 音乐 / 素材一行：对象、授权人、范围、期限、证明文件位置。归档到项目目录。

## 4. 平台规格（默认起点，全部【待核】）

> 下表是**我的经验判断的常见默认值**，用于起草规格，不是平台官方规格。每次交付前去对应平台后台 / 创作者中心确认。

| 平台类型 | 画幅 | 时长 | 备注 |
| --- | --- | --- | --- |
| 抖音 / 快手 / 视频号 / TikTok / Reels / Shorts 等竖屏信息流 | 9:16，1080×1920 | 15–60s 常见；各平台上限不同【待核】 | 静音可看；首 2 秒钩子 |
| 小红书 | 9:16 或 3:4 | 【待核】 | 封面重要 |
| YouTube 横屏 / 品牌站 / 展会大屏 | 16:9，1920×1080 或 3840×2160 | 按用途 | 品牌片多用 24fps |
| 信息流图文视频 | 1:1 或 4:5 | 【待核】 | 重新构图 |
| 投放广告位（含开屏、贴片） | 各平台不同 | 各平台不同 | 以投放后台要求为准【待核】 |

帧率：同一时间线只用一个帧率（社媒 30fps、影视感 24fps 为常见默认，【建议值】）。

## 5. 字幕与安全区

- 竖屏安全区：主体和字幕避开顶部约 15%、底部约 20%（v2 建议值：9:16 时避开顶部 15%、底部 20%）。**各平台 UI 遮挡区不同**【待核】，用平台的「预览」或官方模板确认。
- 字幕：字号够大、对比强、每屏 ≤ 2 行；关键词放在安全区中上部；先过**静音测试**。
- Logo / 角标：避开右侧互动按钮区与底部文案区【待核】。
- 多画幅版本：**重新构图而不是裁切**（见 §7）。

## 6. 音频与导出

- **响度参考**：流媒体 / 社媒约 -14 LUFS integrated；广播 EBU R128 为 -23 LUFS；真峰值 ≤ -1 dBTP（v2 的【已知 / 通用】；**平台具体值【待核】**，以平台规范为准）。
- 对白、音乐、音效**分轨**，需要时导出分轨文件（社区做法，见 `research-notes-x.md` §1 beegnyc）。
- **母版**：ProRes 422 HQ 或等价高质量中间格式；**平台版**：H.264 / HEVC。比特率、编码档位、文件大小上限各平台不同，**【待核】**，不要凭记忆写进客户交付单。
- 导出前检查：画幅 / 帧率 / 色彩空间一致；字幕烧录或外挂符合平台；封面 / 首帧承接钩子。

## 7. 多画幅重新构图检查

| 检查项 | 16:9 | 9:16 | 1:1 / 4:5 |
| --- | --- | --- | --- |
| 主体完整、不被裁掉 | □ | □ | □ |
| 字幕在安全区内 | □ | □ | □ |
| Logo 不变形且位置合规 | □ | □ | □ |
| 产品关键细节可见 | □ | □ | □ |
| 钩子画面在首屏有效 | □ | □ | □ |

如果生成阶段就知道要出多画幅，**在阶段 3 关键帧时就为每个画幅各构图**，比后期裁切更稳（【我的经验判断】）。
