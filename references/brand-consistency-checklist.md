# 品牌一致性检查清单（Brand Consistency Checklist）

> 来源：我的经验判断 + 社区信号。社区里「产品参考板 / REFERENCE LOCK」「以上传图为产品设计、包装、Logo、字体、比例、颜色的唯一依据」的写法见 `research-notes-x.md` §3；「对产品准确性有强迫症」是品牌团队对 AI 剪辑师的招聘要求（§4，招聘帖，仅作旁证）。其余条目是我对品牌项目风险的归纳，**没有 X 数据支撑**。
> 用法：阶段 0 起草并让客户确认 → 阶段 2 固化为资产（v1.0 锁定）→ 阶段 3 / 5 逐项核对 → 阶段 8 终核。
> **硬项** = 不通过即淘汰或重做；**软项** = 记录并酌情放行。

## A. 立项时向客户索取（阶段 0）

| 项目 | 要拿到什么 | 状态 |
| --- | --- | --- |
| Logo | 矢量源文件（SVG / AI / PDF）；主版 / 横版 / 竖版 / 单色 / 反白版；最小尺寸；安全留白规则 | □ |
| 品牌色 | HEX + RGB + Pantone / CMYK（若有）；主色 / 辅色 / 禁用色 | □ |
| 字体 | 品牌字体名、授权状态；屏幕字幕字体是否可替代 | □ |
| 产品 | 官方产品图（多角度、白底、实物照）；尺寸比例；颜色版本（SKU）；包装正反面与细节（文案、条码位、开口方式） | □ |
| 产品细节清单 | 按键 / 接口 / 刻度 / 灯的**个数与位置**；材质与反光特征；易错细节（见 C） | □ |
| 品牌口吻 | 调性词、必说 / 禁说词、slogan 的准确写法与标点 | □ |
| 禁区 | 禁用画面（竞品、争议场景、特定人群 / 宗教 / 政治）、禁用词、行业限制 | □ |
| 审批链 | 谁签脚本、分镜、样片、终片；是否有法务 / 合规节点；反馈格式（时间码批注） | □ |
| 已有素材 | 实拍产品素材、历史广告、VI 手册；授权范围与期限 | □ |

> 没拿到官方产品图和 Logo 源文件，就**不要生成任何带品牌元素的镜头**，先回阶段 0 补资料。

## B. Logo 与文字

- [ ] **版本**：只用客户给的版本；不让模型「生成」Logo（硬项）。
- [ ] **位置与比例**：落版 / 角标位置、占画面比例、留白符合 VI（软项，客户有 VI 手册则升为硬项）。
- [ ] **不变形**：不拉伸、不旋转、不改色、不加特效（硬项）。
- [ ] **叠加方式**：Logo、产品包装上的字、屏幕字幕**一律后期叠加或用实拍 / 合成素材**，不依赖视频模型生成文字（硬项；模型生成的文字常出错）。
- [ ] **文案准确**：slogan、价格、型号、网址、二维码以客户文案为准，逐字核对（硬项）。
- [ ] 品牌落版时长与位置满足客户要求【待核·以客户 VI 为准】。

## C. 产品准确性

- [ ] **形状与比例**：与官方图一致，不同镜头间不变（硬项）。
- [ ] **颜色**：产品色与品牌 HEX 在校色后的目视偏差可接受；多个 SKU 不混色（硬项）。屏幕与印刷色差由客户确认【待核】。
- [ ] **数量与位置**：按键、接口、旋钮、刻度、灯的个数与位置正确（硬项；常见漂移点）。
- [ ] **包装**：正反面文案、条码位、开口方式、标签位置正确。
- [ ] **材质**：金属 / 玻璃 / 磨砂 / 布料的反光与质感符合实物。
- [ ] **使用方式**：演示动作符合真实用法（不能演示产品做不到的事——这同时是合规问题，见 `compliance-and-delivery-specs.md`）。
- [ ] **产品与人的比例**：手持尺寸、佩戴位置合理。
- 路线建议：产品是主角的 A 类镜头，**优先实拍素材或高精度产品图 + 参考锁定**；让模型只生成环境、人物与动势（社区里也有团队用「品牌库真实 B 画面 + 必要时的 AI 镜头」，见 `research-notes-x.md` §4）。

## D. 产品参考板（生成前先做）

做一张或一组图，把产品锁成「唯一依据」，后续每个含产品的镜头都带这张参考图：

- 内容：正 / 侧 / 背 / 俯视或四视图，细节特写（Logo 位、按键、接口、材质），手持比例参考。
- 提示词里写明：以上传图为产品外观、包装、Logo、字体、比例、颜色的唯一依据，不得改动（参考写法见 `research-notes-x.md` §3 的 REFERENCE LOCK）。
- 多参考图时，给每张图标注「这张图锁定什么」（身份 / 产品 / 首帧 / 场景），避免模型混用。

## G. 品牌项目专属风险

- 外部公众对 AI 生成品牌内容的反应可能很强烈：某旅游部门的 AI 宣传视频遭批评，官员事后解释「只是 logo 揭幕视频，不是核心品牌故事」（`research-notes-x.md` §8，新闻转述）。品牌片决定是否用 AI、用到哪个环节，应与客户**明确沟通并书面确认**。
- 品牌方常要求不得出现 AI 可识别的瑕疵；A 类镜头验收标准要比社媒 UGC 高一档。
- 涉及真人代言 / 数字人：见 `compliance-and-delivery-specs.md`。
