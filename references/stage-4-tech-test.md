# 阶段 4 · 技术测试与镜头路线

> 来源：v2 阶段 4。v3 变化：新增「按镜头类型分配模型，不按品牌」与「低成本草稿」两条（社区共识，见 `research-notes-x.md` §2、§5）；工具比较项保留，具体工具名移到 `tools.md`。

**目标**：用最少的测试证明 A 类镜头的关键风险可以达标，并确定每类镜头的工具和参数。

## 步骤

1. 从镜头表「风险」列汇总 A 类镜头的风险清单（一致性、动作完成度、口型、产品准确性、复杂运镜、Logo 可读性等）。
2. 为每个风险设计最小测试：同一关键帧 × 2–3 个候选工具 × 每个工具 2 次【建议值】；提示词和参数保持一致，**一次只比较一个变量**。
3. 用四级筛选给每条测试打分，同时记录单条耗时、单条费用和可用秒数。
4. 计算每可用秒成本 = 总生成费用 ÷ 可用秒数。【计算公式】
5. **（v3）按镜头类型分配模型**：把镜头表按运动类型 / 风险类型分组（人物口播、产品特写、环境氛围、大动作、文字 / 图形），每组各指定主工具 + 备用工具。X 上多位创作者都在说「按镜头选，不要按品牌选」，也有人用同一段脚本跑多个模型对比再选。但这些对比多为个人主观，**以本项目的测试结果为准**。
6. **（v3）低成本草稿**：时间轴、镜头运动和提示词先在低分辨率 / 便宜档位试，锁定后再出最终档位。社区里有人 480p 出草稿再用放大工具出终版；注意这条在 X 上被某平台的推广帖大量放大，独立证据较少，且各工具的草稿档、放大档、价格不同【待核】——所以只作为「先试再放大」的原则，不写死参数。
7. 为每类镜头锁定参数（分辨率、帧率、时长、运动强度、模式、参考方式）。
8. 风险无法达标的镜头回到阶段 1 改设计。

## 路线选择

| 镜头需求 | 首选路线 | 备选路线 |
| --- | --- | --- |
| 构图、产品、品牌必须精确 | 关键帧图生视频（首帧，必要时首尾帧） | 实拍产品 + 合成 |
| 开放式氛围、自然运动 | 文生视频探索 | 选中满意帧后转图生视频 |
| 精确表演、口型、情绪 | 表演驱动或视频到视频；口播见 `ugc-playbook.md` | 真人实拍 |
| 角色跨镜头一致 | 参考图 / 角色锁定 + 固定关键帧 | 改镜头设计：背面、远景、剪影 |
| 长时间连续运动 | 拆成可剪接的多个镜头，或首尾帧接力；若工具支持长单镜头，先小样再放量 | 用形式化设计把漂移变成风格 |
| 对白镜头 | 分开配音，再对口型，或用原生音频 + 外部音频参考 | 画外音 + 反应镜头；原生音频做临时版 |

**参考模式 vs 首尾帧（有分歧，v3 的处理）**：X 上有人偏好首尾帧（跨片段画面构图稳定），也有人偏好多参考模式（身份与场景更稳）。证据都是个例（见 `research-notes-x.md` §6）。v3 的做法：把「首尾帧 vs 参考模式」本身列为 A 类镜头的测试变量，不预设答案。

**工具比较项【待核】**：参考图数量与主体锁定 · 首尾帧 / 多关键帧 · 时长上限 · 分辨率与帧率 · 原生音频与音频参考 · 口型 · 运镜控制 · 商用条款 · 价格 · 排队速度 · 数据隐私 · 是否有水印。
