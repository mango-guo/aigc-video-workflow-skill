# 阶段 3 · 关键帧与动态分镜

> 来源：v2 阶段 3。v3 变化：animatic 工具中立（剪映 / CapCut、Premiere、Final Cut Pro、DaVinci Resolve 均可）；新增「首尾帧 / 多关键帧节拍」「分镜网格」「静帧阶段先在剪辑软件里排节奏」三条社区做法（证据见 `research-notes-x.md` §1–2）。

**目标**：用静帧锁定每个镜头的构图，用 animatic 验证叙事和节奏——**在花视频生成预算之前**。

## 步骤

1. **写关键帧提示词**：`[主体 ID 块] + [动作的起始姿态] + [景别 / 角度 / 焦段] + [构图] + [场景块] + [光线] + [风格块] + [画幅]`。关键帧画动作**开始前**的状态，不画动作中段，给图生视频留出运动空间。
2. **需要首尾帧控制的镜头**（产品转台、变形、精确落位、匹配剪辑、无缝循环背景）同时写尾帧，首尾帧保持同一光线和机位逻辑。若所选工具支持**多关键帧**（例如 X 上有人提到 Kling 4.0 单条 30 秒可放最多 10 个关键帧，每个是镜头必须到达的节拍【待核】），把关键帧当作「节拍点」而不是「装饰」：每个节拍写一句要到达的状态。
3. **（v3）分镜网格**：把一个场次的 4–9 格分镜画在一张图里，既给导演看，也可以整张作为参考图；提示词里必须写「不要显示网格、边框、编号和字幕」，并按格序号逐格播放（社区做法，见 `prompt-and-take-patterns.md`）。
4. **出候选并选定**：每镜头 4–8 张候选【建议值】，按下表检查后选 1 张：

   | 检查项 | 标准 |
   | --- | --- |
   | 构图 | 符合镜头表的景别、角度、构图 |
   | 身份 | 主体 ID 块的锚点特征全部正确 |
   | 场景 | 布局和主光源方向与场景档案一致 |
   | 连续性 | 主体朝向、视线、运动方向与相邻镜头一致 |
   | 运动空间 | 推镜留有裁切余量；横移、摇镜方向留有空间 |
   | 细节 | 手、文字、Logo 无误或可在静帧阶段修好 |
   | 画幅 | 为目标画幅出图，或预留扩图空间 |
   | 品牌（v3，品牌项目） | 按 `brand-consistency-checklist.md` 逐项过 |
   | 真实感（v3，UGC） | 不过度精修；保留手机画质的自然瑕疵（见 `ugc-playbook.md`） |

5. **静帧修复**：用图像编辑工具修手、清理多余元素、扩图到目标画幅、贴回真实 Logo。静帧阶段修复成本远低于视频阶段。【通用】
6. **命名与锁定**：`ABC_SC010_SH020_KF_v002.png`；定稿写入资产库，状态改为「锁定」。
7. **搭 animatic**（任一剪辑软件）：
   - 按交付规格新建项目；静帧默认时长设 3–4 秒后按镜头表逐个调整。
   - 用缩放 / 位移关键帧预示推、拉、移；录临时旁白，放临时音乐；在节拍与卡点处打标记。
   - 每个片段标镜头号，方便审片反馈。
   - 无法剪辑时：把关键帧按顺序排成故事板，配合旁白计时朗读一遍。
   - Final Cut Pro 提示（可选）：设置 → 编辑里改静态图默认时长；用 Ken Burns 或变换关键帧预示运镜；按 M 加标记。
8. **完整播放检查**：开场 1–2 秒是否抓人；信息顺序是否正确；每个镜头是否看得懂；哪些镜头可删、合并或由声音代替；总时长是否达标；再做静音测试和闭眼测试。
9. **回写镜头表**：按 animatic 修正每个镜头时长；生成时长 = 镜头时长 + 首尾各约 0.5–1 秒余量【建议值】。需要多抽卡或后期裁切的镜头，可按阶段 5 的「生成时长 ≥ 镜头时长 × 1.3–2」放宽余量。

**交付物**：定稿关键帧集、animatic v1、更新后的镜头表。

**Gate**：animatic 完整播放时叙事和节奏成立；讲不通就回到阶段 1。

**常见坑**：关键帧画成动作中段；没用固定风格块导致关键帧风格漂移；过早用最终音乐锁死时长；品牌项目的产品细节留到视频阶段才发现错。
