# 阶段 5 · 镜头生产与筛选

> 来源：v2 阶段 5（提示词包、四级筛选、问题标签表、3 轮规则全部保留）。v3 增补：多镜头 / 长镜头的写法、「留够剪辑余量」「告诉模型保留什么」「短镜头多抽卡」。模块与范例见 `prompt-and-take-patterns.md`。

**目标**：让每个镜头得到 1 个通过版和 1 个备选，并留下完整记录。

## 步骤

1. **生产顺序**：A 类（按已测试路线）→ B 类批量 → C 类。先保证整片能剪完，再追加精度。
2. **为每个镜头输出「镜头提示词包」**：

   ```text
   镜头号 / 等级 / 时长：
   镜头目的：
   首帧：关键帧 v__（尾帧：v__，如需要）；参考图：角色 v__ / 产品 v__ / 场景 v__
   运动提示词：主体动作 + 镜头运动 + 节奏（只写一个主要动作）
   风格块：（引用阶段 2，逐字复制）
   避免：变形、多余肢体、乱码文字、多余人物……
   参数：工具 / 模式 / 时长 / 画幅 / 帧率 / 运动强度 / 种子
   通过标准：A ≥ 4 分，B ≥ 3 分
   备选方案：

   示例运动提示词：
   She slowly raises her head and looks at the clock; slow push-in, camera at eye level; calm pacing.
   她缓缓抬头望向时钟；镜头平视缓推；节奏舒缓。
   ```

3. **运动提示词规则**【推断 / 通用】：
   - 一句只写一个主要动作，用具体动词 + 速度副词（slowly、gently、suddenly）。
   - 先写主体动作，再写镜头运动；镜头运动使用标准术语（static、slow push-in、tracking shot）。
   - 图生视频时不要重复描述首帧里的外观，否则容易引发漂移（国内也有创作者把这条表述为「提示词做减法，只给动作指令」）。
   - 不写互相矛盾的指令；5 秒以内的镜头不安排多段动作。
4. **（v3）多镜头 / 长单镜头的写法**：如果工具允许一次生成多个切镜，不要写一整段散文，而是写成带时间码的镜头清单，让模型不必自己猜节奏。例如：`Shot 1 (0–4s): [景别], [运镜]. [动作]. Cut as [触发]. Shot 2 (4–9s): …`（X 上多位创作者 + 官方提示词结构都是这个思路，证据见 `research-notes-x.md` §1；具体语法以所用工具文档为准【待核】）。先用较短片段验证关键帧，再放量生成长片段——长片段很吃额度。
5. **（v3）留够剪辑余量**：按计划镜头长度的 1.3–2 倍生成（至少首尾各 0.5–1 秒）【建议值】，剪辑时再裁最好的一段。
6. **（v3）改一次，说清「改什么」和「保留什么」**：迭代同一镜头时，在提示词里明确列出要保留的元素（构图、角色、音乐节拍），只改一个变量。
7. **生成与记录**：每条生成都记一行（字段见下）。
8. **四级筛选（每项 1–5 分）**

   | 级别 | 检查内容 | 通过标准【建议值】 |
   | --- | --- | --- |
   | 1 意图 | 是否表达镜头目的 | 不达标直接淘汰 |
   | 2 构图与动作 | 构图、动作是否正确、可读 | A ≥ 4，B ≥ 3 |
   | 3 连续性与风格 | 主体朝向、锚点特征、风格能否融入相邻镜头 | A ≥ 4，B ≥ 3 |
   | 4 技术质量 | 闪烁、变形、压缩、帧率 | 能否修复、修复成本是否可接受 |

   品牌项目在第 3 级之后加一道**第 5 级「品牌核对」**：按 `brand-consistency-checklist.md` 的「镜头级」条目逐项过，任一硬项（Logo 变形、产品形状错误、禁用元素）不通过即淘汰，不进入修复。

9. **诊断与重试**：用户发来生成结果时，逐级打分 → 结论「通过 / 待修 / 弃用」→ 如需重试，只指出下一轮**唯一**要改的变量：

   | 问题标签 | 下一轮优先改的变量 |
   | --- | --- |
   | 动作过大、肢体扭曲 | 降低运动强度；把动作描述改得更小 |
   | 主体不动，只有镜头在动 | 把动作动词放到句首并写具体 |
   | 运镜不对 | 改运镜描述，或使用工具的运镜控制 |
   | 面部 / 身份漂移 | 缩短时长；改为中景或远景；增加主体参考 |
   | 风格漂移 | 换回定稿首帧；删掉提示词中额外的风格词 |
   | 闪烁、纹理「沸腾」 | 降低运动强度；换模型 |
   | 穿模、物理错误 | 改镜头设计：遮挡、换角度、拆镜头 |
   | 多余人物或文字 | 首帧中清除；在避免项中写明 |
   | 镜像翻转、朝向错误 | 换首帧；在提示词中写明方向 |
   | 产品 / Logo 变形（v3） | 产品放回静帧阶段修好；视频里让产品少动；Logo 后期贴回 |
   | 画面「太精致、像广告」（v3，UGC） | 首帧改用更生活化的手机质感参考，见 `ugc-playbook.md` |

10. **3 轮规则**【建议值】：同一镜头 3 轮仍过不了二级筛选，就停止重试，升级处理：换路线、改镜头设计或删镜头。
11. **生成记录字段**：镜头号 · 候选编号 · 工具与版本 · 提示词 · 首帧版本 · 参数 · 四级评分 · 问题标签 · 状态（待审 / 通过 / 待修 / 弃用）· 费用。

**Gate**：每个镜头有 1 个通过版 + 1 个备选；生成记录完整；品牌项目的第 5 级核对全部通过。
